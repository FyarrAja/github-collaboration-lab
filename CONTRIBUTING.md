# Contributing

1. Open a feature branch for a genuine improvement or bug fix.
2. Write the code and tests for the same behavior.
3. Run `PYTHONPATH=src python -m unittest discover -s tests -v`.
4. Open a pull request that explains the change, usage, and tests.
5. Request review from a contributor other than the PR author.
6. Only include `Co-authored-by: Name <verified-email>` in a commit message if that person actually worked on that commit, and the email has been verified for their GitHub account.
7. Merge only after reviewing the diff and checking tests.

Do not create empty commits or artificial PRs for badges.
